# 研究报告模板

根据任务复杂度压缩或展开，但保留以下信息。

## 1. 研究结论

用简洁语言回答用户问题，可表达偏积极、中性、偏谨慎或 No Edge，并说明证据强度。列出一个最重要的支持因素、一个最强反方证据和改变判断的条件。不要在摘要中引入正文没有证据的数据，也不要无依据填入置信度数字。

## 2. 范围与数据

- 标的、资产类型、市场代码和基准
- 数据来源、截止时间、区间、频率、币种和复权/净值口径
- 数据充分性：充分 / 部分充分 / 不足
- 关键假设和不可比项

## 3. 核心结果

展示与问题相关的收益、风险、流动性、相对表现、基本面或产品指标。多标的比较优先用紧凑表格；避免输出无助于研究判断的指标堆砌。指出 Fundamental 与 Quant 证据是同向、冲突还是不足。

## 4. 市场预期、Thesis 与驱动因素

在数据支持时说明市场或基准隐含预期、研究观点的核心分歧、3–5 个关键驱动变量、可能催化剂和最强替代解释。分别列出已验证事实、计算结果和合理推断，不把相关关系写成因果关系。

## 5. 风险检查

按“通过 / 警告 / 阻断”汇总数据、市场、产品、模型与 Thesis 风险。严重问题放在结论附近。适合时给出由条件驱动的 Bull / Base / Bear 情景与 Thesis Break；缺少依据时只描述情景条件，不编造概率、目标价或收益率。

## 6. 局限与待补数据

说明缺失字段、披露滞后、样本长度、多来源冲突和无法验证的内容；列出最小补充数据清单。

## 7. 后续研究

给出可验证的下一步，例如延长样本、加入适当基准、验证最强反方证据、做滚动分析或样本外测试。用户要求持续跟踪或复盘时，可建立简洁 Decision Journal；不得擅自执行交易或扩大用户授权范围。

结尾注明：本报告用于研究与信息整理，不构成收益承诺或个性化投资建议。
