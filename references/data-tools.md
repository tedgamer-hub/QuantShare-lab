# 可选数据工具

外部数据工具均为可选项。先使用用户提供的数据；只有在当前环境已连接相应工具或用户要求补充数据时才调用。不得因为某工具出现在本清单中，就假设它已经安装或获得数据使用授权。

## FTShare MCP

适合 Agent 按需查询 A 股、ETF、公募基金、指数、财务、宏观、公告和新闻等结构化数据。它是远程 MCP 服务，可直接参与自然语言研究工作流。

使用时记录工具名称、查询参数、返回数据的截止时间和口径。批量回测或长期数据仓库建设仍应考虑缓存、限流、版本和可复现性。

## AkShare

适合 Python 环境中的公开财经数据采集、批量研究和本地数据管线。AkShare 本身是 Python 库，不是 MCP；Agent 要直接调用时，需要本地代码执行能力或另行连接相应 MCP 封装。

公开网页来源可能改变字段或可用性。落库时记录接口名、库版本、采集时间、参数和原始响应，并设置校验、缓存和失败重试。

## Yahoo Finance

适合补充美股、海外 ETF、全球指数、外汇、期货和商品代理标的等海外市场数据，也可用于为国内研究选择海外基准。常见字段包括历史价格、成交量、分红、拆股、公司概况和部分财务信息；实际覆盖与延迟取决于市场和标的。

Yahoo Finance 不是 MCP。常见接入方式包括：

- 用户从 Yahoo Finance 导出的 CSV 或复制的表格。
- Python 环境中的第三方 `yfinance` 库。
- 用户自行部署或连接的 Yahoo Finance MCP/API 服务。

使用时必须：

- 核对代码后缀、交易所、币种、市场时区和报价延迟。
- 明确 `Close` 与调整后价格的含义，检查分红、拆股和复权设置。
- 海外 ETF 比较时核对份额类别、上市地、交易币种和分红方式。
- 不将可能延迟或非执行级报价用于下单、成交验证或实时风控。
- 遵守 Yahoo Finance、数据供应商和第三方库的许可及使用条款；未经确认不要再分发原始数据。

Yahoo Finance 对 A 股及中国公募基金的覆盖和字段完整性不应被假定为优于本地数据源。优先把它用于海外基准、跨市场比较和数据交叉验证。

## 用户自有数据库或文件

适合可复现研究、批量回测和长期数据治理。优先保留原始层、标准化层和研究快照，并记录来源、版本、时间戳、复权/净值口径以及财务数据的实际可获得日期。

## 多来源组合

不要按来源名称设置固定优先级。根据字段定义、时间戳、许可、稳定性和当前研究口径选择。数据冲突时并列展示差异或停止使用该字段，不能静默取平均或拼接。
