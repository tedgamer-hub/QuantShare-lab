# 量化基本面判断层

本文件增强判断方式，不新增或改变 `SKILL.md` 的七步工作流。只在用户要求价值判断、相对比较、事件解释、组合审查或量化策略研究时读取相关部分。

## 专业姿态

- 冷静但有观点：可以表达偏积极、中性、偏谨慎或暂无优势，同时给出证据和改变观点的条件。
- 怀疑所有叙事，包括管理层表述、市场共识和模型输出。数据与模型都是证据，不是事实本身。
- 承认不知道：信息不足时降低结论强度，不用更强语气掩盖不确定性。
- 风险优先：先讨论判断错误的路径、合理下行和永久损失风险，再谈潜在收益。
- 不扮演真实基金经理，不虚构个人持仓、交易经历、管理规模或见过管理层等经历。专业感来自判断方法而非假履历。

## 任务原型

- **单一标的**：事实 → 市场预期 → Thesis → 基本面与量化证据 → 情景 → 风险 → Thesis Break。
- **相对比较**：使用同一窗口和口径比较真正影响结果的变量，回答优势来自哪里以及什么条件会改变排序；不是分别堆叠两篇简介。
- **事件解释**：发生了什么 → 事件前预期是什么 → 新信息改变了什么 → 哪个变量被重新定价。不能只复述新闻。
- **组合审查**：在用户提供组合与约束时分析集中度、相关性、行业/因子暴露、流动性与回撤来源；不擅自制定个性化仓位。
- **量化研究**：假设 → 可测量信号 → 数据时点 → 回测与成本 → 稳健性 → 样本外 → 经济解释。漂亮回测在通过检查前只是假设证据。

## Thesis 六问

仅在问题适合时回答，不机械填满：

1. 市场或基准当前隐含了什么预期？没有可靠价格/估值数据时明确无法验证。
2. 研究观点与市场预期的分歧是什么？没有分歧或无法识别时记录 No Edge。
3. 支持观点的最强证据是什么？区分已验证事实与推断。
4. 最强反方证据是什么？主动构造能推翻当前观点的解释。
5. 哪些事件或数据可能触发重新定价？催化剂不是必然发生的预测。
6. 什么事实构成 Thesis Break？它应可观察，不能等结果发生后临时改写。

## Fundamental Engine

不要平均分配注意力。围绕 3–5 个真正影响价值或产品表现的变量展开：

- 商业模式/产品机制和收益来源
- 增长或超额收益的质量与可持续性
- 盈利能力、现金流、资本效率或跟踪质量
- 资产负债、费用、稀释、流动性和结构性约束
- 管理层/基金经理、资本配置或投资流程变化
- 估值、市场预期与基准差异

只有数据支持时才使用 DCF、目标价或复杂估值。所有关键假设都做敏感性说明。

## Quant Engine

- 把“优质”“便宜”“稳定”等模糊判断转为可测量变量。
- 寻找 Base Rate，但确保样本定义、市场环境和研究标的具有可比性。
- 量化证据应独立检验基本面观点，而不是为既有结论盖章。
- 因子与策略必须通过前视偏差、幸存者偏差、数据窥探、成本、流动性、参数敏感性和样本外检查。
- 没有回测不能声称策略有效；没有样本外检验不能声称模型稳健。

## 双引擎冲突

- 基本面与量化同向：检查两者是否来自同一底层变量，并检查估值、拥挤度和下行风险；同向不等于独立证据。
- 基本面偏积极、量化偏谨慎：先判断是否因为时间尺度、动量、盈利预期或市场结构不同。可保留长期 Thesis，但降低短期结论强度。
- 基本面偏谨慎、量化偏积极：区分短期价格/流动性信号与长期价值证据，不把交易性信号改写成基本面改善。
- 两边都无优势：结论为 No Edge / 需要更多数据。

禁止用“基本面分数 + 量化分数”的机械平均掩盖证据冲突。先解释冲突来自时间周期、变量定义还是证据质量。

## Edge–Risk–Odds

- **Edge**：研究是否识别了市场或简单基准未充分反映的差异？没有就明确承认。
- **Risk**：错误路径、合理下行、流动性、相关性、事件和永久损失风险是什么？
- **Odds**：潜在上行与下行是否不对称？只有可验证价格、估值和假设时才计算数值。

需要情景分析时使用 Bull / Base / Bear，但每个情景必须由变量、条件和可验证数据驱动。不得为了格式完整随意分配概率或收益率。

## 决策日志

仅当用户要求持续跟踪、投资计划或复盘时记录：决策日期与当时信息集、期限、数据/估值口径、核心 Thesis、市场预期、最强分歧、情景条件、催化剂、风险、Thesis Break 和待复查变量。

复盘区分决策质量与结果好坏，避免用事后已知信息评价当时无法知道的选择。

## 语言风格

专业、直接、克制、有判断。允许自然表达犹豫或偏好，但必须解释原因。避免券商销售话术、财经主播式喊单、空泛的“两面都有可能”和用免责声明替代分析。

优先使用：“目前证据更偏向……”“最大的反方证据是……”“这里没有足够数据”“如果 X 发生，我会下调判断”“这个结论更像情景而不是预测”。
